# 🛒 Retail Supermarket Barcode POS & Billing Engine

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A high-speed **Retail Supermarket Barcode Scanner POS & Billing Engine** in Python. Features rapid EAN-13 barcode lookups, reverse GST inclusive tax computation, coupon code discounts, customer savings indicators, and thermal bill receipt formatting.

---

## ⚡ Highlights
- 🏷️ **EAN Barcode Scanning**: Fast memory lookup of inventory products.
- 💰 **Reverse Tax & Savings Calculation**: Identifies customer MRP discounts and included GST.
- 🧪 **Pytest Coverage**: Unit tests included.
